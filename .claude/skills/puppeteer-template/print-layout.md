# Print Layout Patterns

Page breaks, margins, headers/footers, and multi-page handling for Puppeteer PDF templates.

## Page Size & Margins

### Default A4 Layout

```css
@page {
  size: A4;                    /* 210mm x 297mm */
  margin: 15mm 15mm 20mm 15mm; /* top right bottom left */
}

@page :first {
  margin-top: 10mm;           /* Less top margin on first page (header takes space) */
}
```

### Puppeteer PDF Options

```typescript
const pdf = await page.pdf({
  format: 'A4',
  margin: {
    top: '15mm',
    right: '15mm',
    bottom: '20mm',
    left: '15mm',
  },
  printBackground: true,       // REQUIRED for background colors and images
  preferCSSPageSize: true,     // Use @page CSS rules over these margins
  displayHeaderFooter: false,  // We use CSS-based header/footer instead
});
```

**`printBackground: true`** is critical — without it, all background colors, gradients, and background images are stripped from the PDF.

### Printable Area

With 15mm margins on A4:
- Width: 210mm - 30mm = **180mm** usable
- Height: 297mm - 35mm = **262mm** usable (first page: 287mm - 10mm top)

## Page Breaks

### Force a Page Break

```css
.page-break {
  page-break-after: always;
  break-after: page;
}
```

```handlebars
{{!-- In template: break between rooms --}}
{{#each rooms}}
  <div class="room-card">
    {{> room-header this}}
    {{!-- room content --}}
  </div>
  {{#unless @last}}
    {{> page-break}}
  {{/unless}}
{{/each}}
```

### Prevent Breaking Inside an Element

```css
.no-break {
  page-break-inside: avoid;
  break-inside: avoid;
}
```

Use on:
- Room cards
- Table rows with related data
- Checklist item groups
- Cost summaries
- Any element that looks bad when split across pages

```handlebars
<div class="room-card no-break">
  {{!-- This card will move to the next page rather than being split --}}
</div>
```

### Prevent Orphaned Headers

```css
h2, h3, h4 {
  page-break-after: avoid;
  break-after: avoid;
}
```

This ensures headings aren't left at the bottom of a page with no content following them.

### Table Row Breaks

```css
/* Keep table header visible on each page */
thead {
  display: table-header-group;
}

/* Prevent breaking inside a row */
tr {
  page-break-inside: avoid;
  break-inside: avoid;
}
```

## Headers & Footers

### CSS-Based Fixed Footer

```css
.doc-footer {
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;
  padding: 8pt 15mm;
  font-size: 7pt;
  color: hsl(20, 10%, 38%);
  border-top: 0.5pt solid hsl(30, 15%, 88%);
  display: flex;
  justify-content: space-between;
}
```

**Note**: CSS `position: fixed` in Puppeteer repeats on every page. This is useful for footers but can overlap content at the bottom of each page. Account for this by adding extra bottom margin to `@page`:

```css
@page {
  margin-bottom: 20mm;  /* Extra space for fixed footer */
}
```

### Puppeteer Built-in Header/Footer (Alternative)

For page numbers, Puppeteer has a built-in header/footer system:

```typescript
const pdf = await page.pdf({
  format: 'A4',
  displayHeaderFooter: true,
  headerTemplate: `
    <div style="font-size: 7pt; color: #999; width: 100%; text-align: center; padding: 5mm 15mm;">
      <span class="title"></span>
    </div>
  `,
  footerTemplate: `
    <div style="font-size: 7pt; color: #999; width: 100%; display: flex; justify-content: space-between; padding: 5mm 15mm;">
      <span>Generated by Renovation Agent</span>
      <span>Page <span class="pageNumber"></span> of <span class="totalPages"></span></span>
    </div>
  `,
  margin: {
    top: '25mm',    /* Extra space for header */
    bottom: '25mm', /* Extra space for footer */
    left: '15mm',
    right: '15mm',
  },
});
```

**Available classes** in header/footer templates:
- `<span class="date"></span>` — Current date
- `<span class="title"></span>` — Document title
- `<span class="url"></span>` — Document URL
- `<span class="pageNumber"></span>` — Current page number
- `<span class="totalPages"></span>` — Total pages

**Limitation**: Puppeteer header/footer templates have very limited CSS support — no custom fonts, no flexbox on older Chromium versions. The CSS-based approach is more flexible.

## Multi-Page Patterns

### Pattern: One Room Per Page

```handlebars
{{#each rooms}}
  <section class="room-section">
    <h2>{{name}}</h2>

    {{!-- Room content --}}
    <div class="room-details">
      {{!-- ... --}}
    </div>

    {{!-- Page break after each room except the last --}}
    {{#unless @last}}
      <div class="page-break"></div>
    {{/unless}}
  </section>
{{/each}}
```

### Pattern: Summary Page + Detail Pages

```handlebars
{{!-- Page 1: Executive Summary --}}
<section class="summary">
  <h1>Renovation Plan Summary</h1>
  <div class="summary-stats">
    <div>Rooms: {{rooms.length}}</div>
    <div>Budget: <span class="currency">${{formatNumber totalBudget}}</span></div>
    <div>Timeline: {{estimatedWeeks}} weeks</div>
  </div>
  {{!-- Summary table of all rooms --}}
  <table>
    <thead>
      <tr><th>Room</th><th>Budget</th><th>Status</th></tr>
    </thead>
    <tbody>
      {{#each rooms}}
      <tr class="no-break">
        <td>{{name}}</td>
        <td class="currency">${{formatNumber budget}}</td>
        <td><span class="phase-badge phase-badge--{{lowercase phase}}">{{phase}}</span></td>
      </tr>
      {{/each}}
    </tbody>
  </table>
</section>

<div class="page-break"></div>

{{!-- Pages 2+: Detail per room --}}
{{#each rooms}}
  <section class="room-detail">
    <h2>{{name}}</h2>
    {{!-- Detailed room content --}}
  </section>
  {{#unless @last}}
    <div class="page-break"></div>
  {{/unless}}
{{/each}}
```

### Pattern: Long Checklist (Auto-Flowing)

For checklists that may span multiple pages without forced breaks:

```handlebars
<h2>Room Checklist</h2>
{{#each rooms}}
  <div class="no-break" style="margin-bottom: 16pt;">
    <h3>{{name}}</h3>
    {{#each items}}
      <div class="checklist-item no-break">
        <div class="checklist-item__check {{#if completed}}checklist-item__check--done{{/if}}"></div>
        <div class="checklist-item__text">{{text}}</div>
        <span class="checklist-item__priority priority--{{priority}}">{{priority}}</span>
      </div>
    {{/each}}
  </div>
{{/each}}
```

The `no-break` on each room group ensures items within a room stay together (or move to the next page as a group). Individual items within a room flow naturally.

## Content Spacing Guidelines

| Between | Spacing |
|---|---|
| Document title and first section | 20pt |
| Sections (h2) | 24pt top margin |
| Subsections (h3) | 16pt top margin |
| Paragraphs | 8pt bottom margin |
| Table and surrounding text | 12pt top/bottom |
| Room cards | 12pt bottom margin |
| Page break and next content | 0 (break handles it) |

## Debugging Layout Issues

### Show Page Boundaries

Add this temporary CSS to visualize where pages break:

```css
/* DEBUG: Show page boundaries */
body {
  background: repeating-linear-gradient(
    to bottom,
    transparent 0,
    transparent 277mm,    /* A4 height minus margins */
    red 277mm,
    red 278mm
  );
}
```

### Print Preview Rendering

Generate HTML for preview before PDF:

```typescript
// Save HTML for debugging
await fs.writeFile('/tmp/debug-template.html', renderedHtml);
// Then open in browser to check layout
```

### Common Issues

| Issue | Cause | Fix |
|---|---|---|
| Background colors missing | `printBackground: false` | Set `printBackground: true` |
| Fonts fallback to serif | Fonts not loaded before render | Add `waitUntil: 'networkidle0'` + `document.fonts.ready` |
| Content overlaps footer | Fixed footer overlaps body | Increase `@page margin-bottom` |
| Tables split mid-row | No break protection on rows | Add `break-inside: avoid` to `tr` |
| Heading orphaned at page bottom | No break-after protection | Add `break-after: avoid` to headings |
| Large images overflow page | No max-width constraint | Add `max-width: 100%; height: auto;` to images |
| Blank pages between sections | Extra page-break elements | Check `{{#unless @last}}` guard on page breaks |
